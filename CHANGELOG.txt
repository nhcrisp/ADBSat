# ADBSat (Aerodynamic Database for Satellites)
All notable changes to this project will be documented in this file.

Always keep a [Unreleased] section at the top for tracking changes

## [Unreleased]
### Changed
- File input and output structure changed to use user defined directories
- Update obj_fileTri2patch.m to support generalised matid in .obj files
- Correction in coeff_sentman.m to use Koppenwallner's correction factor rather than Moe's
- Changed determination of whether a triangle is in front of another within shadowing function
### Added
- Diffuse Reemission, Incomplete Accommodation (DRIA) GSI model
- Functionality to allow shadowed panels to be plotted onto model surface
### Removed
- Command line STL to OBJ functionality using meshlabserver depreciated in recent updates
### Fixed
- Units of AoA and AoS in example scripts

## [4.0] - 2026-07-22
### Changed
 - Example scripts have been rewritten to retain compatilibity
 - Inputs files consolidated into a single folder
### Added
 - .stp file compatibility with ADBSat (requires PDE Toolbox)
 - Mesh validation and quality checks, as well as mesh subdivision processes
 - A second shadowing algorithm, which can account for hypothermal flow at the cost of simulation speed
 - GUIs for both single AoA/AoS analysis and full database generation
 - GUI parameter selction can be saved and loaded via a .JSON file
### Removed
### Fixed
 - updated obj_fileTri2Patch.m to simplify file parsing
